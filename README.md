# 🛍️ RevendTout

**RevendTout** est une application web de vente et de rachat d'articles, développée en **ASP.NET Core (MVC)**.

## 🚀 Fonctionnalités
* **Gestion du catalogue** : Affichage des produits disponibles à la vente.
* **Panier d'achat** : Système d'ajout et de modification du panier en temps réel.
* **Paiement sécurisé** : Validation des numéros de carte bancaire via l'**algorithme de Luhn**.
* **Compte Utilisateur** : Inscription, connexion et historique des commandes.
* **Sécurité** : Protection contre les failles CSRF et gestion des erreurs.

## 🛠️ Technologies utilisées
* **Langage** : C#
* **Framework** : ASP.NET Core MVC
* **Algorithme** : Luhn (Validation CB)
* **Frontend** : Razor Views, HTML5, CSS3, JavaScript
* **Données** : Entity Framework Core
